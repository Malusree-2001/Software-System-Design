# Software System Design

A structured learning repository focused on designing scalable, reliable, and efficient software systems.

## Learning Resources

- [System Design Primer — Standalone Edition](https://github.com/mujtbabbas/system-design-primer)
- [Original System Design Primer](https://github.com/donnemartin/system-design-primer)

## Topics Covered

- Client-Server Architecture
- Computer Networking
- REST APIs
- SQL and NoSQL Databases
- Database Indexing
- Load Balancing
- Caching
- Message Queues
- Distributed Systems
- Replication and Sharding
- CAP Theorem
- Scalability
- Fault Tolerance
- Microservices
- Security and Authentication

## Repository Structure

- `Notes/` — Technical concepts and explanations.
- `Architecture-Diagrams/` — System architecture and component diagrams.
- `Case-Studies/` — Independent system design exercises.

## Daily Goals

- Study at least one system design concept.
- Understand architectural decisions and trade-offs.
- Document concepts in my own words.
- Practice designing scalable systems independently.

Develop the ability to independently design, explain, evaluate, and optimize scalable software systems.
